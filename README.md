# 출발 도우미

마곡(회사·숙소)과 기흥 집을 오가는 날, **지금 출발하면 몇 분 걸리고 몇 시에 도착하는지**, **언제 떠나는 게 가장 빠른지** 알려 주는 개인용 웹앱이에요.
휴대폰 사파리에서 https://friese8807.github.io/commute/ 를 열고 공유 → **홈 화면에 추가**해서 써요.

- 요일·시각·공휴일을 보고 다음 길(퇴근 / 출근 / 숙소로)을 저절로 골라요. 칩으로 바꿀 수 있어요.
- 출발 시각별 예상 시간은 카카오모빌리티 '미래 운행 정보'로 받아요. 앞으로 2~4시간을 10~30분 간격으로 살펴봐요.
- 정한 시각에 텔레그램으로 "지금 출발하면 N분, 가장 빠른 출발은 HH:MM"을 보내요.
- 서버 연결 전이나 주소 끝에 `#demo`를 붙이면 예시 길(마곡역 ↔ 기흥역)로 보여요.

## 개인 정보

**집·회사·숙소 주소, 카카오 키, 텔레그램 토큰은 이 저장소에 없어요.** 모두 내 구글 계정의 Apps Script 스크립트 속성에만 저장돼요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면 전체 (지금 / 알림 / 설정) |
| `Code.gs` | 서버 (Apps Script). 카카오 길찾기 호출, 알림 보내기 |
| `.github/workflows/deploy-server.yml` | `Code.gs`가 바뀌면 Apps Script에 자동 배포 |
| `sw.js`, `manifest.webmanifest`, `version.txt` | 홈 화면 앱·새 버전 자동 반영 |
| `icon-*.png`, `icon.svg` | 홈 화면 아이콘 |

## 처음 한 번 준비

1. script.google.com → 새 프로젝트(이름: 출발 도우미) → 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자).
2. 프로젝트 설정 → 스크립트 속성: `KAKAO_REST_KEY`(카카오 REST API 키), `TG_TOKEN`(텔레그램 봇 토큰).
3. 편집기에서 `setup()` 실행 → 실행 기록의 **한 번 누르는 연결 링크**를 휴대폰에서 열거나, 서버 주소·앱 암호를 앱 설정에 넣어요.
4. 앱 설정 → 장소에 회사·집·숙소 주소를 넣고 저장해요.

시험: 편집기에서 `testKakao()`(길찾기), `testTelegram()`(알림)을 실행하면 결과가 실행 기록에 나와요.
